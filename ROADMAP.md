# Roadmap

A public, honest view of where Web3tribe University is going. Items move as we learn; nothing here
is a promise of a date. Want to help with something? Open an issue or see [CONTRIBUTING.md](CONTRIBUTING.md).

## Done
- Role-based access with database-enforced security (RLS, column-protection triggers, server-only reward ledger)
- Admin approval of courses, and re-approval when a live course is edited
- Fixed, non-inflatable W3TR reward economy; rewards paid once per learner per item
- PDF certificates with a public verification page and revocation
- Private course documents with signed, enrolment-checked downloads
- Interface language switcher (English, Hausa, Yorùbá, Igbo) for landing, sign-in and navigation
- Automated attack-replay security tests

## Now
- Open-source basics: governance files, up-to-date docs, automated checks on every pull request
- Dependency and security-header hardening; upload and rate-limit hardening
- Profile privacy: separate public profile data from private contact details
- Account deletion and personal-data export

## Next
- **Credentials people can verify without us:** signed, standards-based credentials (W3C Verifiable
  Credentials / Open Badges) issued alongside the PDF, with a public key, a revocation list, an
  offline verification page and a public specification
- **Offline and low-bandwidth learning:** offline lesson packs and quiz capture with later sync, and a low-data mode
- **Community-owned deployments:** a self-hosting kit and a "hub-in-a-box" local server that syncs to the cloud
- **Languages:** complete Hausa, Yorùbá and Igbo interface coverage with native-speaker review, and per-language courses
- **Accessibility:** WCAG audit, captions and transcripts, keyboard and screen-reader fixes
- **Private course videos** with signed links

## Later / exploring
- Community curriculum and educator charter; open educational resource export with per-course licences
- A transparent, human-reviewed study or translation assistant (only if it clearly helps learners)
- Privacy review of public leaderboards

## Not planned
- Putting learner data or credentials on a public blockchain
- Additional tokens or token-convertibility features
